AQI Prediction
ML Project

03 Model 1 — Linear Regression

Algorithm: sklearn.linear_model.LinearRegression. Each of the 7 targets has its own separate script. The key feature added for each target is TARGET_lag1 (previous day's own value) — providing the autocorrelation signal that makes SO2, NO2, CO, and Ozone predictable without overfitting.

Linear Regression outperforms LSTM on all 7 targets for this dataset. The primary reasons:

  1. TARGET_lag1 feature — Linear Regression explicitly uses yesterday's value, giving it a strong autocorrelation advantage.
  2. Distribution shift — SO2 and NO2 in 2024 are at systematically different levels than 2021–2023. Linear Regression with the lag feature tracks the actual trend; the LSTM struggles to generalise across this shift within a 14-day window.
  3. Dataset size — 1080 training rows is small for deep learning; the LSTM needs more data to fully outperform linear models.

07 How to Run

# Step 1 — Preprocess
python preprocessing/preprocess_csv.py

# Step 2 — Linear Regression (per target)
python models/regression/linear/linear_AQI.py
python models/regression/linear/linear_PM25.py
# … PM10, NO2, SO2, CO, Ozone

# Step 3 — LSTM (per target, GPU recommended)
python models/lstm/lstm_AQI.py
python models/lstm/lstm_PM25.py
# … PM10, NO2, SO2, CO, Ozone
