02 Preprocessing Pipeline

Each audio file passes through a 9-step pipeline (preprocess_db.py) — from loading and resampling to voice-activity detection and conversion to a raw-dB mel spectrogram.

  1. Load with librosa at native sample rate.
  2. Validate sample rate (8,000–48,000 Hz) — skip if invalid.
  3. Resample to 22,050 Hz.
  4. Normalize amplitude.
  5. Remove DC offset (subtract mean).
  6. Pre-emphasis filter (coefficient 0.97).
  7. Voice Activity Detection — 20 ms frames, RMS threshold 1e-4; silent frames discarded.
  8. Chunk into 5-second segments (zero-pad the last chunk).
  9. Mel spectrogram → power-to-dB; output shape (1, 128, 216).

03 Spectrogram Cleaning

Three cascaded passes plus a second-half silence check (clean_db.py) remove silent or low-energy chunks. Pass 2 uses AND logic across three increasingly strict sub-passes — a chunk is removed only if all three conditions are met.

04 Data Augmentation

Five species had fewer than 1,500 clean chunks. Synthetic augmentation (augment.py) brought each up to a 1,500-chunk target — adding 2,988 chunks total. Augmented chunks are used only in training, never in validation or test.

07 Live GUI

The interactive GUI (gui_inference.py) streams your microphone continuously and updates predictions every second — with a live mel spectrogram, per-species confidence bars, and the top prediction highlighted in gold.

  • Load Audio File — classify any .mp3, .wav, .flac, or .ogg file.
  • Start Live — stream microphone; predictions update every second.
  • Species Panel — all 10 species with color dots and live confidence %.
  • Mel Spectrogram — live-updating display alongside confidence bars.

08 How to Run

# Step 1 — Preprocess audio → raw dB .npy chunks
python preprocess_db.py

# Step 2 — Clean spectrograms (3-pass)
python clean_db.py

# Step 3 — Augment underrepresented species
python augment.py

# Step 4 — Train model + generate graphs
python train_db.py
# → checkpoints_db/best_model_db.pth (87.73% accuracy)

# Step 5 — Live testing
python gui_inference.py                       # GUI (recommended)
python inference.py --file path/to/bird.mp3   # file
python inference.py --mic --duration 5        # microphone
